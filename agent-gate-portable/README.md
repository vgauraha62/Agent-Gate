# AgentGate Cage — Portable Deployment

A self-contained AI proxy stack for OpenCode and Claude Code. Routes AI API calls
through a policy enforcement engine with LiteLLM format translation.

## Architecture

```
OpenCode/Claude Code
    │
    ▼  (Anthropic Messages API)
┌──────────┐
│  Proxy   │  port 8080  — License check, content normalization, request forwarding
│  (Go)    │
└────┬─────┘
     │
     ▼
┌──────────┐
│AgentGate │  port 8081  — Policy engine (tool invocation checks, audit logging)
│  (Zig)   │
└────┬─────┘
     │
     ▼
┌──────────┐
│ LiteLLM  │  port 4000  — Format translation (Anthropic ↔ OpenAI)
│          │              routes to Zen API / Anthropic / Ollama
└──────────┘
```

## Quick Start (New Machine)

### 1. One-Command Setup

```bash
tar xzf agent-gate-portable.tar.gz
cd agent-gate-portable
sudo ./setup.sh
```

The script will:
1. Install Docker + prerequisites (curl, openssl)
2. Ask which mode (OpenCode or Claude Code)
3. Prompt for API keys
4. Generate configs from templates
5. Build and start all Docker containers
6. Configure OpenCode CLI (optional)
7. Print success summary

### 2. Or Do It Manually

```bash
# Prerequisites
sudo apt update && sudo apt install -y docker.io docker-compose-v2 curl openssl
sudo systemctl enable docker && sudo systemctl start docker

# Copy config
cp env/.env.opencode.template .env
# Edit .env to set your JWT secret

# Copy and edit LiteLLM config
cp config/litellm-config.yaml litellm-config.yaml
# Edit litellm-config.yaml: replace YOUR_ZEN_API_KEY_HERE

# Generate RSA keys
openssl genrsa -out keys/private.pem 2048
openssl rsa -in keys/private.pem -pubout -out keys/public.pem

# Build and start
sudo docker compose up -d --build

# Wait for health
curl http://localhost:8081/health   # agentgate
curl http://localhost:8080/health   # proxy
curl http://localhost:4000/health   # litellm
```

### 3. Configure OpenCode

Create `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "agentgate/deepseek-v4-flash-free",
  "provider": {
    "agentgate": {
      "name": "AgentGate Proxy",
      "options": {
        "baseURL": "http://localhost:8080",
        "apiKey": "test-key"
      }
    }
  }
}
```

Or run `setup.sh` and let it handle this step automatically.

## Usage

### Start chatting

```bash
opencode
```

### Test the API

```bash
curl -X POST http://localhost:8080/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: test-key" \
  -d '{
    "model": "deepseek-v4-flash-free",
    "max_tokens": 50,
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

### View logs

```bash
docker compose logs -f          # all services
docker compose logs proxy       # just the proxy
docker compose logs litellm     # just LiteLLM
```

### Stop / Restart

```bash
docker compose down             # stop all
docker compose up -d            # start all again
docker compose up -d --build    # rebuild and start
```

### Switch modes

```bash
sudo ./switch.sh opencode       # switch to OpenCode mode
sudo ./switch.sh claude         # switch to Claude Code mode
```

## Secrets You Need

| Secret | Where | How to get |
|---|---|---|
| **Zen API Key** | `litellm-config.yaml` | https://opencode.ai — create an account |
| **Anthropic API Key** | `.env` + litellm (for Claude mode) | https://console.anthropic.com |
| **JWT Secret** | `.env` | Auto-generated by setup.sh |
| **RSA Key Pair** | `keys/` | Auto-generated by setup.sh |

## Switching Between Modes

The package supports two modes via `switch.sh`:

```bash
# OpenCode Mode (default)
# Flow: OpenCode → Proxy → LiteLLM → Zen API (DeepSeek models)
./switch.sh opencode

# Claude Code Mode
# Flow: Claude Code → Proxy → Anthropic API (Claude models)
./switch.sh claude
```

When switching, you must:
1. Run `./switch.sh <mode>` to update `.env` and `config.json`
2. Run `docker compose up -d --build` to restart with new config
3. Update your client config (OpenCode / Claude Code) to point to the proxy

## Troubleshooting

### "Permission denied" for Docker

Add your user to the `docker` group:
```bash
sudo usermod -aG docker $USER
newgrp docker
```

### Proxy fails to start

Check if agentgate is healthy:
```bash
curl http://localhost:8081/health
```

Check proxy logs:
```bash
docker compose logs proxy
```

### LiteLLM returns "No connected db"

This is a known issue with LiteLLM v1.60+. The proxy is still functional
for most requests despite this warning.

### SELinux volume mount errors

If running on a system with SELinux enforcing, add `:z` to volume mounts
in `docker-compose.yml` (already done for `litellm-config.yaml`).
